# 副本（Campaign）规范与模板

## 一、什么是副本

副本（原名战役/模组）是 AI 跑团的冒险单元。它将世界书（规则引擎）、人物卡（角色）和玩家的行动串联在一起，由 AI GM 驱动叙事推进。

**每个副本包含：**
- 一个核心设定（世界观、背景故事、冲突）
- 一个关联的世界书（可选，作为规则和知识库）
- 多个关联的人物卡（NPC/可玩角色）
- 多个会话（章节），每个章节是一次完整的跑团体验
- 对话历史（玩家与 AI GM 的互动记录）

## 三、副本类型

| 模式 | 说明 | GM 类型 | 收费 | 适合场景 |
|------|------|---------|------|---------|
| **solo** | 单人冒险 | AI GM | 1 SEED/次 | 新手体验、单人剧情 |
| **coop** | 多人组队 | AI GM | 0.5 SEED/次/人 | 好友联机、社区团 |
| **human_gm** | 人工主持 | Human | 免费（人工） | 专业 DM 开团 |
| **hybrid** | AI + 人工混合 | Both | 按模式定 | 进阶玩法 |

### 规则体系选择

| 体系 | 默认骰子 | 核心属性 | 适合题材 |
|------|---------|---------|---------|
| **dnd5e** | D20 | 力量、敏捷、体质、智力、感知、魅力 | 西式奇幻、剑与魔法 |
| **coc7th** | D100 | 力量、体质、体型、敏捷、外貌、智力、意志、教育、幸运 | 克苏鲁恐怖、悬疑调查 |
| **shadowrun** | D6 | 力量、敏捷、体质、智力、意志、魅力、边缘、魔法/共鸣 | 赛博朋克、科幻混奇幻 |
| **custom** | D20 | 自定义（简化版） | 中式修仙、都市异能、末世求生等自由题材 |

## 四、AI GM 工作流程

```
玩家输入行动
    ↓
① 加载副本设定 (world_brief)
② 加载关联世界书条目 (lorebook → 关键词匹配)
③ 加载关联人物卡 (asset_links → 注入属性)
④ 加载历史消息 (最近30条，前20条压缩)
⑤ 构建 System Prompt (规则预设 + 世界设定 + 角色信息 + 世界书条目)
⑥ 调用 LLM API (DeepSeek / GLM，支持 SSE 流式)
⑦ 解析响应 → 自动执行 [[D20+N]] 格式骰子
⑧ 保存消息 + 扣除 SEED 费用
⑨ 返回叙事文本（流式或一次性）
```

### 系统提示词构成

AI GM 的系统提示词由以下几部分拼接而成：

```
[规则预设提示词]          ← 根据 system 字段选择
    +
[世界设定 (world_brief)]  ← 副本创建时填写
    +
[世界书条目 (最多8条)]    ← 根据玩家行动关键词自动匹配
    +
[玩家角色属性]            ← 如有关联人物卡
    +
[输出格式要求]            ← 固定指令模板
```

### 骰子语法（在对话中使用）

AI GM 会在叙事中自动插入 `[[ ]]` 标记进行掷骰：

| 语法 | 含义 | 示例 |
|------|------|------|
| `[[D20]]` | 投 1 个 20 面骰 | `[[D20]]` → 15 |
| `[[D20+5]]` | 带加值 | `你尝试说服对方 [[D20+3]]` |
| `[[D20>15]]` | 判定，≥15 成功 | `你潜行过去 [[D20>12]]` |
| `[[D100]]` | 百分骰 | `你调查房间 [[D100]]` |
| `[[2D6]]` | 2 个六面骰之和 | `伤害为 [[2D6]]` |
| `[[3D6K1]]` | 取最高 | `优势判定 [[3D6K1]]` |

## 五、副本创建流程

### 5.1 通过 API 创建

```
POST /api/rpg/campaigns
Content-Type: application/json
Authorization: Bearer <token>

{
  "name": "失落矿坑的诅咒",
  "mode": "solo",
  "system": "dnd5e",
  "world_brief": "费伦大陆北方的剑湾地区，一个废弃的矮人矿坑最近传出怪异的声音...",
  "character_id": "可选，初始角色 ID",
  "lorebook_id": "可选，关联世界书 ID"
}
```

**响应：**

```json
{
  "success": true,
  "data": {
    "id": "自动生成的副本 UUID",
    "sessionId": "自动生成的首章会话 UUID"
  }
}
```

### 5.2 创建流程说明

1. 系统自动将创建者添加为副本成员（`role: 'player'`）
2. 系统自动创建第一个会话（默认标题为"第1章: 序幕"）
3. 如果指定了 `lorebook_id`，AI GM 会在运行时自动注入世界书内容
4. 如果指定了 `character_id`，该角色被设为玩家的初始角色

### 5.3 关联资产（创建后）

副本创建后，可通过资产链接关联更多人物卡：

```
POST /api/rpg/asset-links
{
  "source_type": "module",
  "source_id": "<副本ID>",
  "linked_type": "character",
  "linked_id": "<人物卡ID>",
  "role": "playable_npc"    // NPC / playable_npc / quest_giver / merchant
}
```

## 七、创作规范

### 7.1 world_brief 写作规范

`world_brief` 是 AI GM 最重要的上下文输入，直接影响叙事质量。

**结构建议：**

```
[一段话概括核心冲突]           ← 开门见山，让 AI GM 知道故事的核心驱动

关键地点：                       ← 3-5 个地点，用短横线列举
- 地点1（说明）

势力/角色：                     ← 主要 NPC 和势力
- 势力1（立场和目标）

当前时间/季节：                  ← 提供时间感
```

**写作要点：**
- 用简洁的语言描述，200-500 字为佳
- 不要写完整的剧情线（AI GM 会自动生成）
- 只写"世界是什么样"，不写"玩家应该怎么做"
- 包含足够的冲突元素（势力矛盾、未解之谜、危险区域）
- 关键词尽可能明确（地名、人名、物品名被 AI 识别后会提高叙事一致性）

### 7.2 命名规范

| 要素 | 规范 | 示例 |
|------|------|------|
| 副本名称 | 有吸引力的短名称 | `青牛山试炼` `黄衣之影` `失落矿坑的诅咒` |
| 章节标题 | 格式：`第N章: 章节名` | `第1章: 落雁谷的异动` `第2章: 深坑之下` |
| 文件名（导出时） | 拼音或英文短名 | `qingniu-trial` `yellow-king-shadow` |

### 7.3 定价参考

| 副本类型 | 推荐上架价格 | 说明 |
|---------|-------------|------|
| 短副本（1-2 章，1 小时） | 免费 | 新手引流 |
| 标准副本（3-5 章，2-4 小时） | 50~100 SEED | 主流内容 |
| 长篇副本（6+ 章，5+ 小时） | 100~300 SEED | 深度内容 |
| 套装（副本 + 专用角色卡 + 世界书） | 150~500 SEED | 捆绑销售 |

### 7.4 副本发布检查清单

- [ ] 副本名称已确定
- [ ] `world_brief` 已编写（200-500 字，含冲突、地点、势力）
- [ ] 规则体系已选择（dnd5e / coc7th / shadowrun / custom）
- [ ] 已关联世界书（如需要）
- [ ] 已关联至少 1 个人物卡（如需要）
- [ ] `max_players` 已设置
- [ ] 已选择是否公开
- [ ] 已在异界世场上架（如需要收费）
- [ ] 已用管理员账号完成一次跑团测试

## 八、AI GM 交互协议

### 8.1 发送行动

```
POST /api/rpg/campaigns/<campaignId>
Content-Type: application/json

  "action": "我要仔细检查这个书架，看看有没有暗格",

```
GET /api/rpg/campaigns/<campaignId>

  "data": {
    ...campaign,          // 副本所有字段
    "session": {...},     // 当前活跃会话
    "messages": [...],    // 最近 100 条消息
    "members": [...],     // 成员列表（含角色信息）

  }
}
```

### 8.3 存档

```

{
  "title": "存档名称",

## 九、与人物卡/世界书的关系

```
                 ┌─────────────────┐
                 │    异界世场      │ ← 交易和发现
                 └────────┬────────┘
                          │
     ┌────────────────────┼────────────────────┐
     │                    │                    │
     ▼                    ▼                    ▼
┌──────────┐      ┌────────────┐      ┌──────────────┐
│  人物卡   │◄────►│    副本     │◄────►│    世界书     │
│ (角色)   │      │  (冒险)     │      │  (规则引擎)   │
└──────────┘      └────────────┘      └──────────────┘
     │                    │                    │
     │    资产链接         │    资产链接         │
     │  (role: NPC)       │  (role: NPC)       │
     └────────────────────┴────────────────────┘
```

- **副本 → 世界书**：副本通过 `lorebook_id` 引用世界书，AI GM 运行时自动从世界书中按关键词匹配条目注入上下文
- **副本 → 人物卡**：副本通过资产链接（`source_type: 'module'`）引用人物卡，role 为 `playable_npc` 表示玩家可选的角色
- **世界书 → 人物卡**：世界书通过资产链接（`source_type: 'lorebook'`）引用人物卡，role 为 `NPC` 表示该世界的原生 NPC
