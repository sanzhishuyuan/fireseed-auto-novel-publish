# FireSeed 更新日志

> 记录平台功能更新和重要变更。
> 每次更新后，系统可将此日志内容通过邮件推送给注册用户。

---

## [1.3.0] - 2026-06-11

### 新功能
- 邮件通知系统：新用户注册时自动发送欢迎邮件（含玩法指南）
- 数据库持久化：统一数据库路径（DATA_DIR），杜绝部署时数据丢失
- 自动备份：每日凌晨 3 点自动备份数据库到 Gitee 异地仓库
- 更新通知：管理员可通过 API 向用户群发更新通知

### AI 跑团
- 新增 AI 跑团导航入口
- 修复创建角色时 card_data 参数传反的 BUG
- 支持可配置 LLM 端点（智谱 GLM / DeepSeek 兼容）

### 优化
- 新增 gameplay-guide.md 玩法指南文档
- postbuild.js 优化，不再覆盖数据库文件
- ecosystem.config.js 敏感凭据排除版本控制
