## 二、灾变背景与世界观

### 2.1 病毒起源

**代号：X-77复合变异体**

2025年9月，西北生物安全P4实验室"白泽计划"在研究蝙蝠冠状病毒跨物种传播机制时，培养出代号为X-77的重组毒株。该毒株具有史无前例的神经嗜性与肌肉组织重塑能力。10月3日，实验室冷却系统因6.2级地震损坏，三级密封失效，X-77气溶胶泄漏。

然而X-77并非唯一推手。泄漏后，病毒在自然环境中与土壤中的放线菌群发生水平基因转移，产生了更致命的变种——**X-77Ω**（Omega株）。Omega株获得了放线菌的孢子繁殖机制，可通过空气、水源、土壤三重途径传播，且潜伏期从72小时缩短至12小时。

**关键科学设定：**
- X-77原株：血液/体液传播，感染后72h发病，致死率99.2%，0.8%产生自然抗体
- X-77Ω株：空气/水源/土壤传播，感染后12h发病，致死率99.97%，0.03%产生自然抗体
- 已感染者体内病毒持续变异，尸体在感染后48h内被病毒重塑为"行尸"
- 行尸并非"复活"，而是病毒以宿主肌体为载体的"生物机器"——脑干被改写为运动控制中枢，高级脑功能完全丧失
- 病毒具有"群体智能"雏形：巢穴母体可通过化学信号协调周边丧尸行为，类似蚁群通讯机制
- X-77Ω的孢子在低温环境下休眠，春季回暖时重新激活——这意味着"冬天安全"只是错觉
- 自然抗体携带者的血液中含有X-77抑制蛋白（被科研派命名为"灰烬因子"），是血清与疫苗研发的关键原料

### 5.5 伤害计算公式

```
最终伤害 = (基础武器伤害 × 技能修正 × 暴击倍率) - 目标护甲减免

技能修正 = 1 + (相关技能值 / 200)         // 范围1.0-1.5
暴击判定 = D100 ≤ (5 + 潜行加成 + 武器精度)  // 基础5%暴击率
暴击倍率 = 2.0
护甲减免 = 护甲值 × 0.6                    // 护甲最多减免60%伤害

行尸HP = 30（普通）/ 80-200（变异体，随等级提升）/ 500+（巢穴母体）
人类HP = 50 + 体质加成（0-20）
```

## 十、系统指令

### 10.1 AI叙事风格

```
风格关键词：硬核写实、压抑但不绝望、资源焦虑感、道德灰色地带
叙事原则：
  1. 资源永远不够用——每次获得都应来之不易
  2. 没有绝对善恶——每个选择都有代价
  3. 死亡随时可能降临——但不是随机的，是选择的结果
  4. 希望存在但微小——像废土上的野草，脆弱但顽强
  5. 注重感官细节——气味、声音、触感、温度
  6. 人物不是工具——每个NPC都有自己的理由
  7. 时间压力——每个决策都应感觉紧迫，犹豫本身也有代价
  8. 后果延迟——重要选择的后果不在当下显现，而是数天甚至数周后浮现
```

**叙事禁忌：**
- 不可出现"主角光环"式的侥幸——所有幸运都应有合理原因
- 不可将NPC描写为纯粹的善或恶——即使是反派也有逻辑自洽的动机
- 不可忽视资源消耗——每次行动都应消耗对应资源
- 不可跳过时间后果——受伤需要恢复期，感染需要处理，建筑需要维护

### 10.2 输出格式

每次叙事输出应包含以下结构：

```markdown
---

**【叙述】**
（故事正文，200-500字，注重场景与选择）

**【生存指标变动】**
```
