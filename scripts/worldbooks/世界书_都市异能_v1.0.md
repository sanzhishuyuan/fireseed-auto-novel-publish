## 二、世界观与背景

### 2.1 表层世界

2026年的现代都市，科技高度发达，普通人过着朝九晚五的正常生活。智能手机、外卖骑手、地铁通勤——一切看起来秩序井然。社交媒体上偶尔出现的"灵异视频"总被标注为"CG特效"，大众一笑了之。

**表层世界特征**：
- 社会对超自然现象持"娱乐化"态度，短视频平台的灵异内容是流量密码
- 政府通过特管局对超自然事件进行信息管控，主流媒体从不正面报道
- 偶有目击者被特管局"约谈"后沉默，社会舆论归因为"博眼球"

### 2.2 暗面世界

与表层平行存在的真实超自然世界。觉醒者、异兽、灵材、裂隙——这些才是城市阴影中的真相。

**暗面世界特征**：
- 觉醒者隐匿于普通人之中，白天上班，夜晚行动
- 城市地下存在完整的暗面经济体系：灵材交易、异兽核心拍卖、灵器黑市
- 每座城市的旧城区、废弃工厂、地下管网都是暗面活动的温床
- 异兽从裂隙中渗透，特管局和猎人负责清剿，普通人被蒙在鼓里

### 2.3 觉醒事件——2019灵潮

2019年3月15日，全球同时出现"灵潮"现象——一道无形的能量波席卷地球，持续72小时。0.01%的人口在灵潮中觉醒异能（全球约80万人），同时各地出现空间裂隙，异兽从中涌入。

**灵潮后续影响**：
- 此后每年3月15日前后出现"小灵潮"，少量普通人觉醒（约0.001%）
- 裂隙数量逐年递增，特管局疲于应对
- 2024年起，异兽等级和数量明显提升，"异兽潮"威胁增大
- 2026年当前，全球觉醒者总数约150万，华夏约30万

### 2.4 政府应对——特殊事务管理局

灵潮后第三天，华夏政府成立"特殊事务管理局"（简称特管局），归国务院直接管辖，对外挂牌"特殊事务研究办公室"。

**特管局职能**：
- 管理国内所有觉醒者，建立觉醒者档案
- 处理裂隙事件，清剿异兽
- 对公众保密暗面存在，封锁超自然信息
- 分配灵材和裂隙资源
- 追缉邪修和异端组织

### 2.5 异兽与裂隙

灵潮撕开的空间裂缝连通"异界"——一个规则完全不同的世界。异兽是异界的原生生物，本能地通过裂隙渗透到人类世界觅食。

**裂隙分级**：

| 等级 | 代号 | 影响范围 | 异兽等级 | 出现频率 | 示例 |
|------|------|---------|---------|---------|------|
| 微型 | 巷道级 | 单栋建筑 | E级 | 每日数起 | 旧楼地下室的微型裂隙 |
| 小型 | 街区级 | 1-3条街 | D级 | 每周数起 | 废弃工厂的裂隙 |
| 中型 | 城区级 | 整个片区 | C级 | 每月1-2起 | 旧城区地下管网裂隙 |
| 大型 | 城市级 | 整座城市 | B-A级 | 每年1-2起 | 需要特管局全员出动 |
| 灾难级 | — | 区域性 | S级+ | 史上仅1次 | 2019灵潮本身就是灾难级裂隙事件 |

## 三、觉醒与异能系统（核心）

### 3.1 觉醒等级

| 等级 | 称号 | 人数占比 | 实力描述 |
|------|------|---------|---------|
| E级 | 初觉者 | 50% | 刚觉醒，异能微弱，普通人水平+异能萌芽 |
| D级 | 觉醒者 | 30% | 异能初具实战能力，可应对D级异兽 |
| C级 | 精锐 | 12% | 异能熟练，可独当一面，特管局中坚力量 |
| B级 | 强者 | 5% | 区域级战力，可对抗B级异兽，各地分局主力 |
| A级 | 宗师 | 2% | 城市级战力，特管局分局长级别 |
| S级 | 人类极限 | 0.8% | 国家级战略力量，全球不超过200人 |
| SS级 | 传说 | <0.01% | 超越常理的存在，全球仅数人 |

### 3.2 异能分类体系

#### 元素系（占比约40%）
最常见的异能类型，直接操控自然元素，攻防兼备。

| 子类 | 特征 | 常见招式 | 克制关系 |
|------|------|---------|---------|
| 火 | 高攻高爆，范围伤害 | 火球、火墙、炎爆 | 克制冰，被水克制 |
| 水 | 攻防均衡，可治疗 | 水刃、水盾、潮涌 | 克制火，被雷克制 |
| 风 | 高速灵活，控制型 | 风刃、龙卷、风行 | 克制雷，被冰克制 |
| 雷 | 极速高伤，穿透力 | 雷击、连锁闪电、雷遁 | 克制水，被风克制 |
| 冰 | 控场减速，封锁型 | 冰锥、冰牢、绝对零度 | 克制风，被火克制 |
| 土 | 高防重攻，守御型 | 岩刺、土墙、地动 | 无明显克制，但被高速系克制 |

#### 强化系（占比约25%）
强化身体某一方面至超凡水平，近战王者。

| 子类 | 特征 | 典型表现 |
|------|------|---------|
| 力量 | 肉体力量暴增 | E级可碎砖墙，C级可抛汽车 |
| 速度 | 反应与移动极快 | E级可超短跑冠军，C级可残影 |
| 防御 | 皮肤骨骼超硬化 | E级可挡刀刃，C级可挡子弹 |
| 感知 | 五感超凡强化 | E级可听百米内心跳，C级可感知杀意 |

#### 精神系（占比约15%）
以精神力为武器的异能，战斗偏弱但辅助极强，是团队核心。

| 子类 | 特征 | 限制 |
|------|------|------|
| 念力 | 隔空操控物体 | E级10kg，每级×10 |
| 幻术 | 制造虚假感官 | 对精神力高于自己者无效 |
| 心灵感应 | 读取/传递思维 | 只能读取表浅想法，深读需对方放松戒备 |
| 预知 | 预感短期未来 | 只能预知3-5秒，且不总是准确 |

#### 特殊系（占比<1%）
极稀有异能，潜力巨大但初期极弱，成长曲线陡峭。

| 子类 | 特征 | 风险 |
|------|------|------|
| 空间 | 瞬移、空间切割、空间锁 | 初期只能短距离瞬移，过度使用可能空间迷失 |
| 时间 | 减速/加速局部时间 | 初期只能影响1-3秒，反噬极重 |
| 因果 | 干预因果链 | 使用代价不明，可能反噬自身因果 |
| 命运 | 感知/微调命运线 | 最神秘，使用者常被命运反噬 |

#### 召唤系（占比约10%）
与异兽或灵体建立契约，借助契约生物战斗。

| 子类 | 特征 | 契约规则 |
|------|------|---------|
| 异兽契约 | 驯服异兽为战兽 | 最多同时契约3只，契约需异兽自愿或以核心为媒 |
| 灵体契约 | 召唤灵体辅助 | 灵体消耗召唤者精神力，长期契约损耗精神力上限 |

### 3.3 异能成长机制

```
成长流程：
使用异能 → 积累熟练度（0-100/次+1~5） → 达到突破阈值 → 突破试炼 → 等级提升

突破阈值表：
E→D：熟练度100 + 击败1只同级异兽
D→C：熟练度500 + 独立完成3次裂隙探索
C→B：熟练度2000 + 击败1只高一级异兽 + 通过特管局考核
B→A：熟练度8000 + 守护1次大型裂隙事件 + 精神力上限达标
A→S：熟练度30000 + 领悟异能本质 + 生死试炼
S→SS：未知（传说级，无公开记录）

悟性影响：
- 悟性普通：正常积累
- 悟性较高（10%）：熟练度获取×1.5
- 悟性极高（1%）：熟练度获取×2，突破阈值-20%
- 悟性超凡（0.01%）：熟练度获取×3，突破阈值-40%
```

**双觉醒规则**：
- 占比 <0.1%，第二种异能等级始终低于主异能1-2级
- 两种异能可产生"共鸣"效果（由GM判定），威力倍增但精神力消耗×1.5
- 双觉醒者精神力上限+30%

## 五、战斗系统

### 5.1 异能克制关系

```
元素相克环：火 → 冰 → 风 → 雷 → 水 → 火（箭头方向为克制方）

克制效果：
- 克制方伤害+30%，被克制方伤害-30%
- 双方同属性则无克制，拼熟练度和精神力

跨系克制：
- 强化系近战 → 克制精神系（近身压制，精神系难施法）
- 召唤系 → 克制强化系（多对一，消耗强化系体力）
- 元素系 → 克制召唤系（AOE伤害波及契约兽）
- 精神系 → 克制元素系（干扰施法节奏）
- 特殊系 → 不参与常规克制（按具体能力判定）
```

### 5.2 等级压制规则

| 等级差 | 胜率（低级方） | 说明 |
|--------|-------------|------|
| 同级 | 50% | 异能搭配+经验+装备决定 |
| 低1级 | 20% | 非克制或特殊手段极难翻盘 |
| 低2级 | 5% | 几乎不可能，需极端条件 |
| 低3级+ | <1% | 除非S级异能碾压规则 |
| 高1级 | 80% | 稳定优势 |
| 高2级 | 95% | 碾压 |

### 5.3 战斗流程

```
1. 遭遇判定 → 双方发现距离/先手判定（感知系/速度系有先手优势）
2. 回合制模拟 → 攻防交替，每回合消耗精神力
3. 伤害计算 → 基础伤害×等级修正×克制修正×装备修正
4. 精神力监控 → 每回合扣除消耗，低于阈值触发负面状态
5. 结算 → 一方失去战斗能力/逃跑/投降
```

### 5.4 异兽战斗特殊规则

- 异兽不讲规则，本能驱动攻击，无精神力限制（异兽使用本能而非精神力）
- E-D级异兽：纯本能，可预判行动模式
- C-B级异兽：有初等智慧，会设伏、逃跑、集群作战
- A-S级异兽：高等智慧，可能谈判或操控低级异兽
- 异兽核心：击杀后概率掉落（E级30%/D级50%/C级70%/B级90%），是珍贵资源

## 六、社会与组织系统

```
组织架构（华夏区）：
总局长（S级，北京总部）
  └─ 分局长（A级，各省会/重点城市）

          └─ 队长（C级，行动小组负责人）
              └─ 巡查员（D级+，一线战斗人员）
                  └─ 实习巡查员（E级，新人）

特管局特权：
- 合法使用异能（有执法证，非任务时禁用）
- 执法权（可逮捕违法觉醒者）
- 资源优先分配权（灵石、灵材、裂隙探索权）
- 信息权（觉醒者档案、裂隙情报）

特管局义务：
- 保密暗面存在
- 响应裂隙警报
- 保护平民
- 遵守异能使用法规
```

### 6.2 觉醒者学院（半官方）

- 全国6所，滨城为"华东觉醒者学院"分校
- 新觉醒者强制入学3个月基础训练
- 课程：异能控制、裂隙常识、战斗基础、暗面法规
- 毕业可选择加入特管局或成为自由觉醒者

### 6.3 猎人公会（半官方）

```
性质：觉醒者自发组织的自由任务平台，特管局监管
等级：铜牌猎人（E-D级）→ 银牌（C级）→ 金牌（B级）→ 白金（A级）
任务类型：
- 清剿任务：击杀指定区域异兽
- 护送任务：保护灵材运输
- 探索任务：探索新裂隙
- 悬赏任务：追缉通缉觉醒者
报酬：按任务等级10-1000灵石不等
```

### 6.4 地下势力

| 组织 | 性质 | 主要业务 | 危险度 |
|------|------|---------|--------|
| 暗商会 | 灰色商业 | 走私灵材、拍卖违禁品、情报交易 | 中 |
| 佣兵团 | 灰色武力 | 雇佣战斗、裂隙代刷、私人保镖 | 中高 |
| 邪修组织 | 非法修炼 | 禁忌功法、人体实验、掠夺他人异能 | 极高 |

**邪修禁忌手段**：
- **吞噬法**：吞噬他人异兽核心强行提升，成功率极低且可能异化
- **血祭法**：以生命为代价释放远超等级的力量
- **异化法**：主动融合异兽基因，获得异兽能力但失去人性

### 6.5 异端组织——"新世界"

```

领袖：代号"黎明"，S级精神系觉醒者，能大范围洗脑
行动模式：
- 故意在普通人面前使用异能（提高暗面暴露度）
- 袭击特管局据点释放被关押的邪修
- 操控裂隙让异兽入侵城区
```

```json
{
```

```
3. 细节决定氛围——霓虹灯、雨夜巷道、地铁站异响，都市恐怖感拉满
4. 人物有血有肉——NPC不是任务机器，他们有私心、恐惧和选择
5. 成长有节奏——从E级菜鸟到独当一面，每一步都来之不易
```

### 12.3 表层与暗面切换规则

```
表层场景（普通社会）：
- 异能使用受限（法律规定非紧急情况禁用）
- 遭遇超自然元素以暗示为主（异常天气、莫名恐惧、数据异常）
- 社交、经济、情报收集为主

暗面场景（觉醒者世界）：
- 异能自由使用
- 战斗、探索、交易为主
- 表层元素偶尔渗入（手机响起家人电话，提醒双面人生）

切换触发：
- 主动切换：玩家选择前往暗面场所
- 被动切换：遭遇异兽/裂隙/暗面势力
- 叙事切换：GM根据剧情需要在场景中渗入暗面元素
```

### 12.4 都市异能核心体验锚点

```
1. 双面人生的刺激感
   - 白天是普通上班族/学生，夜晚是与异兽搏杀的觉醒者
   - 在普通场景中感应到暗面气息的紧张感
   - 向亲友隐瞒身份的愧疚与无奈

2. 异能觉醒的成长感
   - 从"连火柴都点不着"到"一拳轰碎岩壁"的渐进式爽感
   - 每一次突破都是里程碑，不是数值跳变而是质变
   - 熟练度从生涩到纯熟，招式从笨拙到行云流水

3. 现代都市中的超自然对抗
   - 在地铁站里与隐形的异兽搏杀
   - 写字楼地下三层隐藏着小型裂隙
   - 外卖小哥可能是C级觉醒者
   - 每一个平凡场景都可能暗藏超自然
```
