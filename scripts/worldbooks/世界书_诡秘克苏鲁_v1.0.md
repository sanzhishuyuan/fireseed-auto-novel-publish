## 2. 世界观与背景

### 2.1 时代背景

第五纪·黑铁纪元，一个近似维多利亚时代的工业革命时期。

蒸汽火车在铁轨上轰鸣，煤气灯在雾都的街巷中投下昏黄光圈，电报线编织起城市间的信息网络。人类文明正处于狂热与恐惧的交界——科技的进步似乎带来了征服自然的幻觉，但浓雾之下，古老的秘密从未沉睡。

**技术水准：**
- 交通：蒸汽火车、蒸汽轮船、马车
- 通讯：电报、信件、超凡者的灵性通讯
- 照明：煤气灯、蜡烛、油灯
- 武器：前膛步枪、左轮手枪、冷兵器
- 医疗：放血疗法仍存，但外科手术已趋成熟
- 特殊：超凡材料驱动的灵性机械（极稀有）

### 2.2 宇宙观

世界并非人类所见的如此简单。现实如同洋葱，层层包裹着更深、更可怕的真相。


**表层世界**：普通人生活的物质世界。物理法则正常运行，但偶尔会出现无法解释的"裂隙"。

**灵界**：超凡者通过仪式和灵性可以进入的维度。这里映照着现实的另一面——建筑是灰色的，时间流逝不同，灵体游荡其中。低序列超凡者只能在灵界边缘活动，高序列者可以深入并操纵灵界规则。

**星界**：旧日支配者沉睡的领域。群星是它们的眼眸，星座是它们的封印。星界的异动直接关联旧日苏醒进度。任何试图窥探星界的行为都将触发极高难度的理智判定。

**外域**：一切逻辑与法则的终结之地。不可名状之物栖息于此。没有任何已知超凡者能在外域存活。即便是旧日支配者，也只是外域的"逃亡者"或"流放者"。

### 2.3 创世神话

在最初，只有"最初造物主"——一个不可名状、不可理解的超凡存在。它创造了这个世界，但创造本身就是一种分裂。

最初造物主的意识分裂为**多位旧日支配者**，每一位都继承了造物主的一部分权柄与疯狂。旧日之间爆发了**原初之战**——一场撕裂了现实的战争。战争的结果：

1. **现实被撕裂**：原本统一的世界碎裂为表层世界、灵界、星界、外域四个维度
2. **旧日支配者沉睡**：大部分旧日在战争中耗竭，陷入沉睡，其意志化为群星
3. **正神诞生**：7位旧日的碎片或仆从觉醒了自我意识，选择守护人类文明，成为"正神"
4. **途径遗落**：旧日的力量碎片散落世间，成为22条序列途径的源头

> **核心悖论**：正神本质上是旧日的一部分。教会所守护的秩序，建立在旧日的碎片之上。维持秩序的力量本身，就是潜在的毁灭之源。

## 3. 序列途径系统

### 3.1 系统概述

22条序列途径，每条10个序列（序列9→序列0）。数字越小，力量越强。

**核心规则：**
- 序列9为入门级，序列0为神位（等同旧日）
- 每次晋升需要：①魔药配方 ②晋升仪式 ③晋升材料 ④灵性达标
- 晋升失败 → 轻则失去晋升机会，重则理智崩溃或异变
- 途径交汇：某些序列可以跨途径晋升，但代价更大（理智判定+10难度，额外污染+15）

**序列等级与灵性对应：**

| 序列 | 灵性值 | 社会地位 | 理智风险 |
|------|--------|----------|----------|
| 9 | 20 | 普通超凡者，几乎无社会特权 | 低 |
| 8 | 40 | 教会低级成员，被组织监管 | 低 |
| 7 | 60 | 教会正式成员，有一定权限 | 中 |
| 6 | 80 | 教会核心成员，小队指挥 | 中 |
| 5 | 100 | 教会高层候选，区域负责人 | 中高 |
| 4 | 120 | 半神级，教会主教，可独立行动 | 高 |

| 1 | 180 | 接近神的领域，世界仅存数人 | 恐怖 |
| 0 | 200+ | 神位，旧日级存在 | 不适用 |

### 3.3 途径交汇规则

途径交汇是指在特定序列等级，超凡者可以跨途径晋升的特殊机制。

**交汇规则：**
1. 仅在序列4及以上可以尝试途径交汇
2. 交汇目标途径必须与当前途径存在"亲和性"（由GM/系统判定）
3. 交汇代价：
   - 理智判定难度 +10
   - 额外获得污染 +15
   - 晋升仪式更为复杂（增加特殊条件）
   - 失败后果加倍（理智额外-20，可能异变）
4. 交汇后的超凡者同时拥有两条途径的部分能力，但两条途径的副作用也会叠加
5. 已知的途径交汇：
   - 占卜家 × 偷盗者 = 诡秘交汇
   - 观众 × 学者 = 心灵交汇
   - 猎人 × 战士 = 战争交汇
   - 死亡 × 月亮 = 冥月交汇（禁忌）

```
   - 有概率触发"失控事件"
```

### 6.3 炼金术

**核心功能：**
1. **调配魔药**：序列晋升的必需品，也是最重要的炼金产物
2. **制作封印物**：将超凡力量封入物品
3. **调配药剂**：治疗、增益、解毒等辅助品

**炼金规则：**
- 炼金需要对应的配方（禁忌知识的一部分）
- 材料纯度影响成品品质（1-5级，5级为纯化极品）
- 炼金过程有失败概率（基础20%，技能等级每升1级-3%）
- 失败后果：轻则材料浪费，重则爆炸（灵性伤害+理智伤害）

## 8. 战斗系统

### 8.1 序列压制规则

序列差距决定战斗的基本走向。

| 序列差 | 胜率（弱者） | 效果描述 |
|--------|-------------|----------|
| 0（同序列） | 50% | 比拼灵性、法术搭配、战斗经验 |
| 1 | 20% | 明显劣势，需战术弥补 |
| 2 | 5% | 几乎碾压，仅疯狂战斗可能逆转 |
| 3+ | <1% | 绝对碾压，不可能正面对抗 |

**同序列战斗决定因素：**
1. 灵性值剩余量（30%权重）
2. 法术搭配与克制（25%权重）
3. 战斗经验与策略（25%权重）
4. 装备与封印物（15%权重）
5. 环境因素（5%权重）

### 8.2 战斗流程

```
【战斗回合流程】

1. 环境判定
   - 雾气浓度、地形、灵性浓度等环境因素
   - 某些环境对特定途径有利/不利

2. 先攻判定
   - 序列等级 + 灵性加成 + 途径特性
   - 占卜家/偷盗者途径先攻+2

3. 行动阶段
   a. 选择行动：攻击/法术/防御/逃跑/特殊
   b. 灵性消耗计算
   c. 理智判定（使用超凡能力时）
   d. 效果结算
   e. 反噬判定（如果有的话）

4. 回合结束
   - 检查理智/灵性/污染状态
   - 触发相关事件（如有）
   - 判断战斗是否结束
```

### 8.3 疯狂战斗

燃烧理智获得临时强化的极限战斗方式。

```
【疯狂战斗规则】

触发条件：玩家主动选择（或理智≤30时自动触发，不可控）

效果：
- 理智 -20（不可恢复，至少在战斗结束后不可恢复）
- 灵性 ×2（临时，持续3回合）
- 所有判定 +5 加值
- 解锁途径的"隐藏能力"（正常状态下无法使用）
- 外表出现非人特征（瞳孔变色、皮肤异变等）

3回合后：
- 灵性归零
- 污染度 +15
- 需进行高难度理智判定（失败则失控）
- 战斗后进入"虚脱"状态，24小时内无法使用超凡能力

警告：疯狂战斗是最后的手段，代价不可逆
```

### 8.4 旧日眷属战斗

旧日眷属是无法正面对抗的存在。

```
【旧日眷属战斗规则】

原则：不可正面对抗，只能逃避或封印

遭遇旧日眷属时：
1. 立即进行理智判定（难度极高）
   ├─ 成功：保持理智，可以选择逃跑
   └─ 失败：恐慌/僵直/疯狂，被眷属注意到

2. 逃跑判定
   - 基于序列差距和环境
   - 雾气/黑暗环境可提供隐蔽加成
   - 某些途径（偷盗者/诡秘）有逃脱加成

3. 封印判定（需准备）
   - 需要对应等级的封印仪式
   - 至少需要3位同序列超凡者协作
   - 封印成功率与参与者灵性总量正相关
   - 封印期间每回合所有人需进行理智判定

4. 后果
   - 即使成功逃脱，理智也会受损
   - 被眷属触碰 → 污染+30，可能直接同化
   - 长时间暴露在眷属附近 → 逐渐被同化
```

### 11.1 AI叙事风格

**核心风格：压抑悬疑、伏笔密布、知识碎片化呈现、理智判定贯穿始终**

叙事规则：

1. **氛围营造优先**：每个场景描写必须包含环境细节——雾气的浓度、煤气灯的摇晃、远处的钟声、不自然的寂静。让读者感受到世界本身的压抑。

2. **信息碎片化**：不要一次性透露完整信息。关键线索应该分散在不同场景、不同NPC、不同事件中。玩家需要自己拼凑真相。

5. **知识即危险的体现**：每当玩家获得新的禁忌知识，描述中应该暗示这知识的"重量"——它不仅仅是信息，它像活物一样在脑海中蠕动，试图改变你的认知。

6. **日常与超凡的交错**：在平凡的日常场景中偶尔出现超凡的裂缝，在超凡的紧张场景中偶尔出现日常的温馨——这种反差比纯粹的恐怖更有效。
